# Gully Pit Stop

A responsive Indian street-food menu with a racing circuit, checkered flags, house-special Maggi and Chai, and generated illustrative food images.

## Run locally

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Run from this directory. No build or dependency installation is required. Optional Google Fonts fall back to system fonts. Menu filters and variant selectors run in the browser; selectors do not place orders.

## Menu

- Idly: Regular or Millet Idly.
- Dosa: Plain, Ghee Karam, Onion, or Masala; Regular or Millet batter.
- Puri and Punugulu.
- Maggi, Fried Rice, and Noodles: Veg, Egg, or Chicken.
- Millet Pongal and Chai.

Food imagery in `assets/food-grid.png` is AI-generated and illustrative. Prices, location, and contact details can be added when available. GitHub Pages serves the root of `main`.
