# Gully Bandi

A responsive Indian food truck menu with Maggi and Chai house specials and category filters.

## Run locally

From this directory, run:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

The site uses plain HTML, CSS, and JavaScript; no build or package installation is required. Google Fonts are optional; system fonts are used when unavailable. Prices, location, and contact details can be added when available.
